Valid Input for Integers

Some pages are labelled as for integers. Integers have the following format: strings containing only the characters '0'-'9' with no leading '0's. That is, the first character cannot be a 0.

Examples of valid integer input

100, 123456789, 7, 99

Examples of invalid input

00000001, 022, 1.99, &77, @!#@$, abc

Valid Input for Terminating Decimal Numbers

  • Some pages are labelled as for rational numbers or rationals.
  • Rationals or terminating decimals/TDs have the following format:
  • A string containing digits: "0"-"9", and possibly the sign "-" and decimal point ".". If it has no "." it's the same format as a positive or negative integer.
  • If it has a "-" it has only one and it is the first character.
  • If there is a "." then it can't be the first character nor can it be the last. There can be no leading 0s to the left of it (if there is no "-" then the first character cannot be "0" unless the second character is ".").
  • If there is a "-" then the second character cannot be "0" unless the third is ".".
  • We call the digits to the right of the decimal point the tail. The tail is a string of digits; this string can have leading 0s but cannot be all 0s.
  • '0' cannot be the last digit if the string has a '.'.

Examples of valid rational input

0.00001, 9.88, -23, -0.6

Examples of invalid input

2.0, 5.&, 789.00000

Valid Input for Positive Binary Integers

Some pages are dedicated to binary integer arithmetic. A binary integer contains only the characters '0' and '1'. The exception is the number 0.

Examples of valid integer input

100, 101, 100000000

Examples of invalid input

000001, 00

Page Layout

The body of each page of the AAA has roughly the same layout from top to bottom:

  1. Text fields for punching in either valid integers or rationals, or a dropdown for input.
  2. One or more buttons that perform an arithmetic operation.
  3. A display area for the visuals (some pages will have two, with the second for Napier's Bones).
  4. Control buttons for the animations.
  5. Labels for text output.
  6. A button that links to the next demo.
the display areas will show an animation or some other visual generated by pressing the arithmetic buttons. pages that display animations will have control buttons.
IMPORTANT: The "start" control button will take you back to the first frame of the animation. while the "play" button will play the animation from the current frame, stopping at the last frame. This means that if you want to play the animation from start to finish press start and then play
